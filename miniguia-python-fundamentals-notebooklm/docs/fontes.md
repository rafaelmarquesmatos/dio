# Fichamento — Curadoria de Fontes (Python Fundamentals)

## F1 — The Python Tutorial (docs.python.org/3/tutorial)
- **Tipo:** Documentação oficial
- **Capítulos usados:** 3 (Informal Intro), 4 (Control Flow), 5 (Data Structures), 9 (Classes - opcional)
- **Por que é confiável:** mantida pela Python Software Foundation, atualizada para Python 3.12
- **Como citar no NotebookLM:** `F1 cap. X`
- **Exercício sugerido:** reproduzir todos os exemplos no REPL e variar entradas

## F2 — Beginner's Guide + Library Reference
- **Links:** https://wiki.python.org/moin/BeginnersGuide + https://docs.python.org/3/library/
- **Foco:** primeiros passos, instalação, built-ins essenciais (print, input, len, range, open)
- **Dica:** use `help(len)` no REPL para ver docstring na prática

## F3 — Automate the Boring Stuff with Python (Al Sweigart)
- **Link:** https://automatetheboringstuff.com/
- **Capítulos usados:** 1 (Basics), 2 (Flow Control), 3 (Functions), 4 (Lists), 5 (Dictionaries)
- **Destaque:** exercícios com automação real (manipular arquivos, planilhas)
- **Licença:** leitura gratuita online

## F4 — PEP 8 Style Guide
- **Link:** https://peps.python.org/pep-0008/
- **O que extrair:** naming (snake_case), indentação (4 espaços), imports, docstrings, E/W códigos
- **Uso prático:** rodar `pip install pycodestyle && pycodestyle seu_arquivo.py`
